    Domande frequenti

    I miei PDF vengono caricati su un server?

    No. PrivaPDF elabora tutto localmente nel tuo browser tramite WebAssembly e le API del browser (pdf-lib e pdf.js). I file non lasciano mai il tuo dispositivo.

    L'oscuramento è davvero permanente?

    Sì. Le pagine con aree oscurate vengono rasterizzate ad alta risoluzione con i rettangoli neri già "fusi" nell'immagine: il testo sottostante non è più presente nel file scaricato e non può essere selezionato o recuperato.

    Funziona senza connessione?

    Sì. Dopo la prima visita puoi installare PrivaPDF come app (PWA). Il Service Worker mette in cache l'app e le librerie, così continua a funzionare completamente offline.

    È gratis?

    Completamente gratis e senza registrazione. Se ti è utile, puoi sostenere lo sviluppo con una donazione volontaria.

    Ti è stato utile?

    PrivaPDF è gratis, privato e senza limiti. Se ti fa risparmiare tempo proteggendo i tuoi dati, un piccolo contributo aiuta a tenerlo online.

    Come funziona la privacy di PrivaPDF

    Quando apri un PDF, il file viene letto solo nella memoria del tuo browser. L'elaborazione (unione, divisione, rotazione, oscuramento) avviene tramite WebAssembly e le API native del browser, direttamente sul tuo dispositivo.

    • ✈️ Funziona anche offline, come una vera app.
